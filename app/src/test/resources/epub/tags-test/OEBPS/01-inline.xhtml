01. Inline formatting

Every line below must show its style.

em: this text must be italic

i: this text must be italic

strong: this text must be bold

b: this text must be bold

s: this text must be struck through

del: this text must be struck through

strike: this text must be struck through

H2O — “2” as a subscript

E = mc2 — “2” as a superscript

1030 years — superscript digits in a number

1st, XXth — sup made of LETTERS

xi + yn — sub made of LETTERS

code: this text must be monospace

Mixed: italic with bold inside and back.

Italic inside a word: unbelievable — must work, because it is a mark, not “_”.

Italic with a space inside the tag: word yours next — the space must stay, the words must not run together.

Bold with spaces around: text bold next — the words must not run together.

DELIBERATELY UNSUPPORTED: u: underline — must stay plain text WITHOUT an underline, because the reader draws links with an underline.

EXPECTED: every line styled except the last one.
