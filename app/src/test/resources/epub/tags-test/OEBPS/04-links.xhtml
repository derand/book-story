04. Посилання

4.1. Зовнішнє посилання: приклад посилання — підкреслене й клікабельне, підкреслення в URL має вціліти.

4.2. Посилання з http має стати https: старий протокол.

4.3. Внутрішнє посилання на якір нижче: перейти до позначки.

4.4. Посилання з форматуванням усередині: жирний текст посилання — без видимих зірочок.

4.5. Це позначка anchor1 — сюди веде 4.3.

ОЧІКУВАНО: 4.1, 4.2, 4.4 відкривають браузер; 4.3 нікуди не веде поза книжкою.
